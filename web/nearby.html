How is this request protected?

Your CLI and this page use one-time X25519 keys to create an encrypted channel. Comparing the host public key prevents the relay from silently substituting its own key. The derived key is protected with AES-256-GCM, so the relay only sees ciphertext. Remembering a key requires a second approval.
